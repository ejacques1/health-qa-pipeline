Phase 1
Data Collection & Readability Scoring
1
Supabase — Database
Stores all 100 health questions
Each question is marked as pending, then updated to complete once processed
2
ChatGPT API (GPT-5.2)
Generates a health information response for each question
Temperature set to zero — locks responses so they are identical each time, enabling other researchers to replicate the study. Response quality is equivalent to what a regular ChatGPT user would receive.
3
Readability Scoring
Calculates Flesch-Kincaid Grade Level & Flesch Reading Ease on ChatGPT's response text
URLs are removed from the text before scoring to prevent artificially inflated grade levels
4
Source URL Extraction
Extracts all source URLs cited in ChatGPT's response
One row is created per source URL for individual source analysis
5
Supabase + Google Sheets
Results saved to both the database and Google Sheets for review
Full response, readability scores, and source URLs stored
Phase 2
Source Organization Classification
6
Google Apps Script
Automated rule-based classification — no AI involved
Runs directly inside Google Sheets on each source URL
7
Three-Stage Classification
Each source URL is identified through a three-step process:
Stage 1: Known domain lookup — checks the URL against ~80 known health websites
Stage 2: Web address analysis — checks the URL ending (.gov = Government, .edu = Academic)
Stage 3: Webpage analysis — visits the page and examines behind-the-scenes code for clues about the organization type

8
Human Verification
Manual review of all automated classifications in Google Sheets
Unclassified or uncertain sources reviewed and coded by hand

Cleaned data ready for descriptive statistical analysis: readability scores, source URLs, and organization type classifications
